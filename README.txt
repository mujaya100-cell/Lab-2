ЛАБОРАТОРНАЯ РАБОТА № 2 — ВАРИАНТ 5
===================================

ГЛАВНЫЙ ФАЙЛ: lab2_variant5.py

ФАЙЛЫ ПРОЕКТА
  lab2_variant5.py   — программа на Python
  books.csv          — исходные данные о книгах (НЕ ИЗМЕНЕНЫ)
  currency.xml       — исходные данные о валютах (НЕ ИЗМЕНЕНЫ)
  bibliography.txt   — 20 библиографических ссылок с нумерацией
  currency_lists.txt — два списка: CharCode и Value
  unique_tags.txt    — все уникальные жанры / теги
  top_20_books.txt   — 20 самых популярных книг

КАК ЗАПУСТИТЬ В VS CODE
1. Распакуйте архив в отдельную папку.
2. Откройте папку проекта в VS Code (File > Open Folder).
3. Откройте терминал в этой папке (Terminal > New Terminal).
4. Запустите: python lab2_variant5.py
   Если Windows не распознает команду python: py lab2_variant5.py
5. Введите имя автора для поиска (например, Пушкин).
   Можно нажать Enter, чтобы пропустить поиск.
6. Результаты будут показаны в терминале и сохранены в текстовых файлах.

ЗАДАНИЯ
1. Подсчет записей, где длина названия книги > 30 символов.
2. Поиск по автору без ограничений (вариант 5: «Нет»).
3. Генерация и сохранение 20 библиографических ссылок.
4. Парсинг XML: два отдельных списка CharCode и Value.
5. Допзадание: список тегов без повторений.
6. Допзадание: 20 самых популярных книг по количеству выдач.

ВАЖНЫЕ ПОЯСНЕНИЯ
- books.csv разделен символом «;» и использует кодировку cp1251.
- Дата поступления — это НЕ год издания. В books.csv нет отдельного поля
  «Год издания». В библиографии используется год из «Дата поступления»;
  при защите нужно прямо об этом сказать преподавателю.
- Популярность определяется столбцом «Кол-во выдач». Для одинакового
  ID книги количество выдач из нескольких строк суммируется.
- В строке «Жанр книги» отдельные теги разделяются символом #.
- Значения Value в XML содержат десятичные запятые; Python преобразует
  их в точки и переводит в тип float.
- Для выполнения лабораторной не нужны дополнительные библиотеки:
  csv и xml.dom.minidom входят в стандартную библиотеку Python.
- Статистика (statistics), PyCharm, pandas и установка пакетов не нужны.
